## 1. โค้ดที่ไม่ได้ถูกเรียกใช้ — ลบทิ้ง

| ที่ | ลบอะไร | ทำไมมั่นใจว่าไม่ได้ใช้ |
|---|---|---|
| `backend/app/api/routes/rfqs.py`, `portal.py` | `from pathlib import Path` | ไฟล์ไม่ลงดิสก์แล้วตั้งแต่ย้ายไป MongoDB |
| `backend/app/services/storage.py` | `BOM_SUFFIXES` | การตรวจนามสกุลไฟล์ BOM ย้ายไปอยู่ใน `bom_service.parse_upload` แล้ว |
| `backend/app/services/bom_doc.py`, `rfq_doc.py` | `BOM_SUBDIR`, `RFQ_SUBDIR` | เส้นทางที่เรียกจริงส่ง `kind="rfq_doc"` ตรง ๆ ไม่ได้อ่านค่าคงที่นี้เลย |
| `frontend/app/(app)/products/page.js` | `import Link` | หน้านี้เปลี่ยนไปใช้ `router.push` หมดแล้ว |
| `frontend/app/(app)/products/[...part]/page.js` | `encodePart` | เลิกประกอบ URL เองในหน้านี้ |
| `frontend/app/(app)/vendors/[id]/page.js` | `OtdBadge` (ตัว default) | หน้านี้ใช้แค่ `OtdSummary` |
| `frontend/components/icons.js` | `IconContact`, `IconMatch`, `IconBox` | ไอคอนของสามหน้าที่เลิกใช้ไปแล้ว (contacts / matching / items) |
| `frontend/app/globals.css` | 90 บรรทัด | คลาสของหน้าที่ถูกลบ (`.vendor-card`, `.chip-btn`, `.badge.type-*`), แถบล่างแบบเก่า (`.sticky-bar` — ถูก `.bulk-bar` แทน) และคลาสที่ค้างจากธีมน้ำเงิน |

ตรวจด้วย `pyflakes` ฝั่ง Python และสคริปต์ไล่ import/export/คลาส CSS ฝั่งหน้าเว็บ
แล้วยืนยันซ้ำด้วยการรันชุดทดสอบทั้งหมด

**สองอย่างที่เกือบพลาด** — บันทึกไว้เพราะเป็นกับดักของการ "ลบสิ่งที่ดูเหมือนไม่ได้ใช้":

* `SkeletonText` ไม่ถูก import จากไฟล์อื่นเลย แต่โครงหน้า **ทุกตัวในไฟล์เดียวกัน** เรียกใช้มัน
  ลบแล้วทุกหน้าขึ้น "This page couldn't load" — ตอนนี้เปลี่ยนเป็นฟังก์ชันภายในไฟล์ (ไม่ export)
  ซึ่งตรงกับความจริงมากกว่า
* `encodePart` ไม่ได้ใช้ในหน้าสินค้า แต่ **ใช้ในหน้าผู้ขาย** — เกือบลบผิดไฟล์

ทั้งสองจุดจับได้เพราะรันชุดทดสอบซ้ำหลังลบ ไม่ใช่เพราะอ่านโค้ดแล้วเห็น

## 2. ชุดทดสอบ — ย้ายเข้าโปรเจกต์จริง

เดิม `api_check.py`, `e2e.mjs`, `testserver.py`, `seed_epicor.py` อยู่นอกโปรเจกต์
README อ้างถึงมันแต่ในเครื่องคุณไม่มีไฟล์เหล่านี้ — ชุดทดสอบที่เอกสารบอกว่ามี

## 3. เทสต์ที่หดตัวเองได้ = เทสต์ที่เชื่อไม่ได้

`theme_check.mjs` มีบั๊กเงียบ: ถ้ายังไม่มีโครงการหรือใบขอราคาในระบบ มันจะ **ข้าม**
หน้า BOM กับหน้าผู้ขายไปเฉย ๆ แล้วรายงานว่า "ผ่านหมด" ด้วยจำนวนข้อที่น้อยลง
(23 ข้อแทนที่จะเป็น 35) โดยไม่มีอะไรบอกว่าตรวจไม่ครบ

ตอนนี้เพิ่มสามข้อที่ตรวจว่า "มีข้อมูลให้ตรวจจริงไหม" ถ้าไม่มีจะ FAIL ตรง ๆ
รวมเป็น 38 ข้อ

## 4. `.gitignore`

เพิ่มของที่ชุดทดสอบสร้างขึ้นระหว่างรัน — `_shots/` (ภาพหน้าจอ Playwright)
และ `*.pkl` (ข้อมูลจำลอง) ทั้งสองอย่างสร้างใหม่ได้ทุกครั้งที่รัน

## 5. ของที่ผมลบให้ไม่ได้

ผมลบไฟล์บนเครื่องคุณไม่ได้ (เขียนทับได้อย่างเดียว) — แต่ตรวจแล้วว่าเครื่องคุณ
**ไม่มี** `backend\app\_removed\` กับ `frontend\_to_delete_pages\` อยู่แล้ว
สองโฟลเดอร์นั้นมีอยู่แค่ในสำเนาที่ผมทำงาน และลบทิ้งไปแล้ว

เหลือที่คุณตัดสินใจเองได้:

* `_to_delete\` ที่รากโปรเจกต์ — ของเก่าจากรอบก่อน ๆ ลบได้เลย
* `_*.tgz` แปดไฟล์ที่ผมส่งมาแต่ละรอบ — แตกไปแล้วทั้งหมด ลบได้
* `backend\uploads\` — เหลือไฟล์เก่า 3 ไฟล์ที่ยังไม่ได้ย้ายเข้า MongoDB
  **อย่าเพิ่งลบถ้ายังไม่ได้รัน** `python scripts\migrate_uploads_to_mongo.py`
